# User Flows

Based on the core features of the TradeDNA platform:

## 1. Prospect Discovery Flow
1. **User (Exporter)** logs into the platform.
2. User navigates to the "Prospects" section.
3. User enters search criteria (e.g., region, industry).
4. System returns a list of verified international buyers.
5. User saves or shortlists relevant prospects.

## 2. Outreach Messaging Flow
1. User selects a saved prospect.
2. User drafts or selects a template for outreach.
3. System sends the message and tracks delivery/open status.
4. User monitors responses in the platform.

## 3. Compliance Check Flow
1. User views a prospect profile.
2. System displays relevant compliance insights for trading with that prospect's region.
3. User reviews insights to ensure trade viability.
