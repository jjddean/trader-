## Overview

Every submission, amendment, cancellation, and HMRC notification is stored in an immutable audit log. The compliance audit page shows the full history for your account.

## Notification Types

| Code | Meaning |
|------|---------|
| DMSACC | Declaration accepted by CDS |
| DMSCLE | Goods cleared |
| DMSREJ | Declaration rejected |
| DMSINV | Declaration invalidated |
| DMSCTL | Control (goods held for examination) |

## Evidence Chain

For TDR (Trader Dress Rehearsal) and production submissions, the full notification chain is preserved:
- Raw XML payload stored verbatim
- `X-Conversation-ID` linked to every notification
- Timestamps for each state transition
