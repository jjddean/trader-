## What is an HS Code?

A Harmonised System (HS) code is a 10-digit commodity code used to classify goods for UK customs. The correct code determines:
- The duty rate payable
- Required supporting documents
- Any licences or restrictions

## Using HS Code Lookup

Navigate to **Compliance → HS Code Lookup** in the dashboard. Enter a description or partial code to search the UK tariff.

## Verifying Requirements

Before submitting a declaration, verify the document requirements for your commodity + origin combination at:

```
https://www.trade-tariff.service.gov.uk/commodities/{HS_CODE}?country={ORIGIN}
```

Example for frozen poultry from Brazil:
```
https://www.trade-tariff.service.gov.uk/commodities/0207129000?country=BR
```
