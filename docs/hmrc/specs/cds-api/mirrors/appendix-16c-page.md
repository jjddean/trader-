# Maritime ports and wharves location codes for Data Element 5/23 of the Customs Declaration Service

> Source: https://www.gov.uk/government/publications/maritime-ports-and-wharves-location-codes-for-data-element-523-of-the-customs-declaration-service
> Retrieved: 2026-05-27

Find the codes which can be used in Data Element 5/23 to identify the location where the goods may be examined for maritime ports and wharves (Appendix 16C).

From: HM Revenue & Customs Published 10 December 2018 Last updated 18 May 2026

## Details

Using the relevant codes from the list, enter the location where the goods are held at the time of making the declaration, separate guidance is available for Roll on Roll off (RoRo) movements.

The code for the location to be declared in Data Element 5/23 is shown in column 3.
