# XML Reference

## Field descriptions

In the table below, the ‘Requirement’ column indicates whether the presence of a data class/element is necessary when submitting Entry Summary Declarations (where applicable), or whether it is always present in a notification or outcome:

- M - Mandatory (must always be provided)
- O - Optional (must be provided if available)
- C - Conditional (either mandatory or optional, depending on the conditions applicable to this class)
