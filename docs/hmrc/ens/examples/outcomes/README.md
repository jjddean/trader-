# Outcome examples

HMRC publishes no downloadable example payloads for the Outcomes API.

The OpenAPI specification for `import-control-entry-declaration-outcome` v1.0
references the response schemas but ships no `externalValue` example instances,
unlike the Declarations API.

Inline XML fragments for the list-outcomes and retrieve-outcome responses appear
in the service guide mirror at
[`../../api/service-guide-api-reference.md`](../../api/service-guide-api-reference.md)
("Getting outcomes"). Those are illustrative fragments in HMRC's prose, not
published files, so they are not reproduced here as if they were artifacts.

Schemas to validate real responses against: [`../../schemas/outcomes/`](../../schemas/outcomes/).

Recorded in [`../../SOURCES.md`](../../SOURCES.md) §7.
