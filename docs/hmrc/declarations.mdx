## Declaration Types

FreightCode currently supports **H1** — standard frontier import declarations for goods released into free circulation in the UK (CPC 40 00).

## Creating a Declaration

1. Go to **Declarations → New Declaration**
2. Enter origin country, HS code, and description
3. The declaration is created as a **Draft**

## Goods Items

Each declaration requires at least one goods item with:

| Field | Description |
|-------|-------------|
| Commodity code | 10-digit HS code (DE 6/14) |
| Procedure code | 4-digit CPC, e.g. `4000` (DE 1/10) |
| Additional procedure | 3-digit code, e.g. `000` (DE 1/11) |
| Origin country | ISO 2-letter country code (DE 5/16) |
| Gross weight | KG (DE 6/5) |
| Net weight | KG (DE 6/1) |
| Supporting documents | e.g. N853, Y930, Y929 (DE 2/3) |

## Submission

Click **Submit** in the declaration workspace. FreightCode will:
1. Validate all required CDS fields
2. Map to WCO DEC-DMS:2 XML
3. POST to HMRC CDS
4. Store the `X-Conversation-ID` for notification tracking

A successful submission returns a **202 Accepted** and moves the declaration to **Processing** status.
