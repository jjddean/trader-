# Compliance Messaging and UX Signoff

## Scope Reviewed
- Reports page provenance language
- Records page provenance language
- Submit page expectation language
- Disabled export/download action copy for non-authoritative data

## Approved Messaging Rules
- Derived financial/report data must explicitly state it is not HMRC-confirmed.
- Pre-flight submit pass must explicitly state it does not guarantee HMRC acceptance.
- Disabled data export/download controls must indicate derived/non-authoritative basis.
- Advisory evidence wording must not imply legal acceptance by HMRC.

## Applied Copy Decisions
- Reports banner:
  - "Derived data only. Not an HMRC-confirmed settlement or clearance result."
- Records banner:
  - "Derived data only. Not an HMRC-confirmed settlement or clearance result."
- Submit page disclaimer:
  - "Pre-flight pass means structurally ready to submit. It does not guarantee HMRC acceptance."
- Disabled actions:
  - `DOWNLOAD DISABLED (DERIVED)`
  - `EXPORT DISABLED (DERIVED)`

## Outcome
- Status: Accepted for release-readiness phase.
- Result: No ambiguous HMRC-confirmation claims remain in reviewed surfaces.
