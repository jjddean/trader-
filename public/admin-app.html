HMRC Integration

Customs Declaration Service (CDS) API integration

OAuth 2.0 Flow

1️⃣ User clicks "Connect HMRC" → Settings → Security
2️⃣ Redirected to HMRC Government Gateway login
3️⃣ User authorises the application
4️⃣ Callback at /auth/hmrc/callback exchanges code for tokens
5️⃣ Tokens stored in hmrc_tokens table
6️⃣ Auto-refresh before expiry (4 hour lifetime)

Notification Types

✅ DMSACC

Declaration accepted — MRN assigned

❌ DMSREJ

Declaration rejected — error codes returned

🔄 DMSROG

Routed for examination

✅ DMSCLE

Declaration cleared

⚠️ DMSINV

Validation errors — field-level details

💰 DMSTAX

Tax calculated

🛃 DMSCTL

Customs control flagged

📨 DMSRES

Additional response data

Rate Limiting

3 req/sec default (upgradable to 8 via SDH Support)

Proactive token-bucket limiter at src/lib/rate-limiter.ts. Reactive retry on HTTP 429 with 2s → 5s backoff.

Runbook

Operational procedures for system outages and recovery

HMRC API Unavailable

Detect: HTTP 5xx errors from HMRC, or API Status page alerts.
Action: Enable circuit breaker; queue declarations in Processing.
Notify: Inform users via dashboard banner & email.
Verify: Monitor HMRC API status; successfully process 1 test declaration.

HMRC

Convex Outage

Detect: Convex dashboard alerts, unresponsive app.
Action: Fallback to status page. Halt HMRC webhooks (they will retry).
Notify: Emergency channels, tweet status, update status page.
Verify: Convex resolves issue; check webhook queue drains.

Database

Clerk Auth Failure

Detect: Users report 401s, redirect loops, or Clerk status alerts.
Action: Check Clerk status. No local mitigation (auth is fully delegated).
Notify: Update status page with "Login issues".
Verify: Clerk resolves issue; users can log in successfully.

Auth

Cloudflare R2 Storage Down

Detect: Document uploads fail, R2 API returns 5xx.
Action: Disable document upload buttons. Allow declarations without documents if permitted.
Notify: Users see "Document upload temporarily unavailable" inline.
Verify: Test upload of 1 test document succeeds.

Storage

Typesense Search Down

Detect: Search API times out or typesense cloud alerts.
Action: Fallback to basic DB search (Convex) where possible, or disable typeahead.
Notify: Users see "Advanced search disabled".
Verify: Typesense reports green; perform a search query successfully.

Search

HMRC Error Codes

Mapping DMS responses to FreightCode logic

DMS Notification Types

Notification TypeMeaningFreightCode ActionUser Sees
DMSUB Declaration Submitted / Received by HMRC Update status to 'Submitted' "Submission Received" info card
DMSACC Declaration Accepted, MRN generated Update status to 'Accepted', store MRN "Accepted ✅" with MRN
DMSCLE Declaration Cleared Update status to 'Cleared' "Cleared 🟢"
DMSROG Routed for Examination Update status to 'Action Required' "Under Review ⏳"
DMSREJ Declaration Rejected outright Update status to 'Rejected', parse errors "Rejected ❌" + Error Details
DMSINV Invalid - Validation Errors Update status to 'Invalid', parse field errors "Validation Failed ⚠️" + Errors

HTTP Error Codes

400 Bad Request

Malformed XML or JSON submission formatting error.

401 Unauthorized

OAuth Token invalid/expired. App automatically attempts refresh.

403 Forbidden

EORI not whitelisted, lacking scopes, or token revoked.

404 Not Found

Querying an MRN that HMRC does not recognize.

422 Unprocessable

Schema validation error caught before routing.

429 Too Many Requests

Rate limit exceeded (3 req/sec). App pauses and retries.

Incident Response

Procedures for security and data incidents

Data Breach Procedure

1. Notify: Internal team immediately.
2. HMRC Notification: Contact HMRC Software Developer Support within 24h.
3. ICO Reporting: Report to ICO if PIP / PII is exposed within 72h.
4. User Notice: Alert affected workspaces via email.

Security Disclosure

All security vulnerabilities should be immediately routed to:
security@freightcode.co.uk
Expected initial response time: < 4 hours.

Response Time SLAs

P1 (Critical Outage): 15 mins response, 2 hours mitigation.
P2 (Partial Outage): 1 hour response, 4 hours mitigation.
P3 (Bug): 24 hours response, Next Sprint fix.

Agent Authorisation

Recording representative authority for customs submissions

⚠️ Implementation Missing

The declarations schema lacks explicit fields for Authorisation Type, Importer EORI (DE 3/16), and Date of Authority. Currently it only holds a generic eori field.

Required Fields for Brokers

  • Broker EORI must be recorded (DE 3/21)
  • Importer EORI must be recorded (DE 3/16)
  • Authorisation type must be recorded (Direct vs Indirect)
  • Date of authorisation

Webhook Configuration

Push notifications endpoints from HMRC DMS

HMRC Production

  • Endpoint URL: https://freightcode.co.uk/api/hmrc/webhooks/notify
  • Authentication: HMRC signed payload
  • Expected events: DMSUB, DMSACC, DMSCLE, DMSROG, DMSREJ, DMSINV
  • Retry policy: HMRC retries for 24 hours on failure
  • Response: Must be HTTP 200

HMRC Sandbox

  • Endpoint URL: localhost is not reachable by HMRC directly.
  • Simulation: Use local webhook simulation for testing routines.
