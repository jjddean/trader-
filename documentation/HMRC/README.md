# HMRC Documentation

This folder separates HMRC material by authority. Future agents and contributors should not treat every markdown file as current truth.

## Authority Levels

- `source-material/`: untouched official HMRC or GOV.UK references copied into the repo. These files are source evidence, not project interpretation.
- `internal-guidance/`: current project guidance, operational rules, and known-good H1 behavior constraints.

Superseded HMRC plans and older AI-generated research live under `documentation/archive/hmrc-stale/`.
