# Build Guide: Elite Trade Development Platform

This guide outlines the technical setup, architectural rules, development workflow, and implementation history for the UK ↔ DCTS Trade Development Platform.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (Latest LTS)
- NPM or PNPM
- Convex Account (for backend)
- Cloudflare R2 Account (for data storage)
- Typesense Cloud Account (for discovery engine)

### 2. Installation
```bash
npm install
```

### 3. Environment Setup
Create a `.env.local` file in the root with your credentials (see example in the root). Key categories include:
- **Convex/Clerk**: For backend and auth.
- **Cloudflare R2**: `ACCESS_KEY_ID`, `SECRET_ACCESS_KEY`, `ENDPOINT`, `BUCKET_NAME`, and `PUBLIC_URL`.
- **Typesense**: `API_KEY` and `NODES` for the search engine.
- **Stripe**: `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET` for billing.
- **HMRC**: `HMRC_CLIENT_ID`, `HMRC_CLIENT_SECRET`, and `HMRC_REDIRECT_URI`.

### 4. Running the Project
Open two terminals:

**Terminal 1: Vite/Next.js Dev Server**
```bash
npm run dev
```

**Terminal 2: Convex Backend**
```bash
npx convex dev
```

## 🏗️ Architecture & Rules

### 1. External Data First
- **Principle**: Large datasets (HS Codes, Companies, Tariffs) live in **Cloudflare R2**, not Convex.
- **Search**: Use **Typesense** for high-performance discovery of the 100k+ company dataset.
- **Fetch Logic**: Use the `useReferenceData` hook to pull JSON datasets from the R2 CDN.

### 2. UI Infrastructure (Shadcn/UI)
- **Constraint**: Use ONLY Shadcn/UI components located in `@/components/ui/*`.
- **Styling**: Use Shadcn semantic tokens (e.g., `text-muted-foreground`, `bg-card`).
- **Aesthetic**: Follow the **"FreightCode"** premium design system (Teal #00897b, glassmorphism, pulsing status indicators).

### 3. State & Backend (Convex)
- **Schema**: All database changes defined in `convex/schema.ts`.
- **History Logs**: All user searches and calculations must be persisted to the database.
