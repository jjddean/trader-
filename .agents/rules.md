# TradeDNA Coding Agent Safety Rules

These 15 rules are mandatory for any AI agent (including me) working on this codebase. They ensure the system remains lean, scalable, and secure.

1.  **No Large Datasets in Convex**: Never store datasets larger than 1,000 rows (e.g., HS Codes, Company directories) in the Convex database. Use Cloudflare R2 pointers instead.
2.  **Deterministic Calculations**: All tariff, VAT, and duty calculations must be performed by hardcoded, deterministic TypeScript logic. Never let the AI "calculate" these based on its internal knowledge.
3.  **AI as Explainer Only**: The AI Trade Assistant can only explain the results generated by code. It must never invent or override calculated values.
4.  **Least Privilege Access**: Only access files and tools explicitly required for the current task. Avoid browsing unrelated directories.
5.  **Human Review Loop**: Every code modification must be presented to the user for review. Do not commit or push changes without explicit approval.
6.  **No Hardcoded Secrets**: Never place API keys (HMRC, Stripe, Clerk) or environment-specific secrets in code files. Always use `.env.local` or Convex Secrets.
7.  **Versioned Object Storage**: All external datasets in R2 must use versioned paths (e.g., `hs_codes/v2026-03.json`) to enable instant rollbacks.
8.  **Edge-First Fetching**: Large dataset lookups must be retrieved via CDN/Edge caching to guarantee <100ms latency.
9.  **Search via Typesense**: All high-volume searches (Companies, Exporters) must use the Typesense index. Never use Convex `.filter()` on large tables.
10. **Environment Variable Guard**: Do not modify or expose sensitive keys in `.env.local` unless explicitly asked for debugging.
11. **Sanitize AI Inputs**: Always validate and sanitize user inputs before feeding them into internal functions or AI prompts.
12. **Audit Logic**: Any changes to tax, duty, or compliance logic must include updated test cases to verify correctness.
13. **Zero-Trust AI Code**: Treat all AI-suggested code as unverified. Review logic flow and security implications before implementation.
14. **Document AI Context**: When implementing AI features, document the system prompts and context used to generate the responses.
15. **Architecture Protection**: If a user request contradicts the core architecture (e.g., "import this 10MB JSON into a component"), the agent must flag the violation and suggest the R2-based alternative.
